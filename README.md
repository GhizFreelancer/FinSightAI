# FinSight AI

AI-powered financial document processing
and expenditure analytics platform.

## Project Overview

FinSight AI aims to automate financial
document processing, extract structured
information from invoices, and provide
financial insights through data pipelines
and AI-powered assistance.

## Planned Technologies

- Python
- PostgreSQL
- Pandas
- FastAPI
- OCR
- Local AI models
- Prefect
- Docker

In development.
